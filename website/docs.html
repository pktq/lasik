Docs

LASIK runs from npx with Node.js 20.19 or newer. No native dependencies, no network calls, no telemetry, and it never executes the code it reads.

Quick start

# 1. How blind would an agent be?
npx lasik-agents scan ./dist
# 2. Write a cleaned copy next to it (./dist.lasik)
npx lasik-agents heal ./dist
# 3. Point REA (or any coding agent) at the healed copy
npx -y rea-agents@latest analyze-javascript-application "$PWD/dist.lasik" --json

heal never touches your files: it writes a copy to <path>.lasik, or wherever -o says. Files without BLA evidence are copied byte-identical.

Connect your agents

setup registers npx -y lasik-agents mcp with every coding agent it finds: Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI, Windsurf, Antigravity, VS Code, Copilot CLI and OpenCode. doctor checks Node, npx, which agents are registered, and whether REA is installed.

npx lasik-agents setup                         # every client found
npx lasik-agents setup --client cursor --dry-run # one client, preview only
npx lasik-agents setup --remove                # unregister
npx lasik-agents doctor

For any other MCP client, add the server by hand:

{
  "mcpServers": {
    "lasik": { "command": "npx", "args": ["-y", "lasik-agents", "mcp"] }
  }
}

Agents that load skills also get the LASIK skill, with BLA fingerprints and a REA workflow in its references.

CLI reference

The binary is lasik (also lasik-agents). This is its own help text:

$ lasik --help
LASIK 0.2.0 · LLM Agent Sight In Kode
BLA blinds your agent. LASIK gives it its sight back.

Usage
  lasik scan <path>            Detect BLA hardening and score how blinded an agent would be
  lasik heal <path> [-o dir]   Write a cleaned copy an agent (or REA) can read (default: <path>.lasik)
  lasik firewall [file|-]      Redact LLM-directed decoy text from any text (stdin with -)
  lasik bench <dir>            Heal every target under <dir> and print a before/after table
  lasik setup                  Register the LASIK MCP server with your coding agents
  lasik doctor                 Check Node, npx, agent registrations and REA
  lasik mcp                    Run the MCP server on stdio

Options
  --json                 Machine-readable report
  --md                   Markdown report
  -o, --out <dir>        Output directory for heal
  --aggressive           Also fold predicates proven only by sampling, and shake files without BLA fingerprints
  --no-firewall          Don't run the prompt firewall
  --strict-firewall      Redact every prompt-decoy match, even in runtime strings (read view; may change behaviour)
  --no-rename            Keep BLA's renamed module handles
  --fail-on <level>      Exit 3 when the verdict is at least <suspected|blinded> (for CI)
  --client <id>          setup: only this client (repeatable): claude-code, claude-desktop, cursor, codex,
                         gemini-cli, windsurf, antigravity, vscode, copilot-cli, opencode
  --dry-run              setup: show what would change
  --remove               setup: unregister

LASIK never executes the code it reads. Use it on software you own or are authorised to analyse.

scan

Detects BLA layers and scores how blinded an agent would be, without writing anything. The verdict is clean with no strong findings, blinded at a blindness score of 40 or more, and suspected otherwise. The score is a weighted sum of the layers found (tarpit 25, entangle 20, deceive, encrypt, prompt and exhaust 15 each, runtime 10), capped at 100. How the score works.

heal

Writes the cleaned copy: JavaScript and TypeScript bundles, inline scripts in HTML, Electron ASAR archives (offsets rewritten), WebAssembly including .wasm.gz (re-encoded and checked with WebAssembly.validate, never instantiated), source maps, Electron fuses and Python. --md prints a Markdown report you can attach to an issue.

npx lasik-agents heal ./app -o ./app.lasik
npx lasik-agents heal ./app --md > lasik-report.md

firewall

Redacts text written to steer a model (fake chat turns, refusal bait, false "no business logic here" claims, canaries, dual-use bait, fake compliance notices) from a file or standard input. Each redaction leaves a marker saying what was removed and why. 38 rules in six categories; the rules.

cat strings.txt | npx lasik-agents firewall -

bench

Heals every target under a directory (each subdirectory is one target) and prints a before/after table. This site's numbers come from lasik bench bench/bla-crackme.

MCP tools

ToolWhat it does
lasik_scanDetect BLA layers in a file or directory: blindness score 0–100, AI-evasion techniques, token savings
lasik_readReturn one JS/TS/HTML file with BLA removed and the strict firewall applied: what the agent should read instead of the original
lasik_healWrite a cleaned copy of a whole app for REA or the agent
lasik_firewallRedact prompt decoys from any text before reasoning over it

The JSON report

--json prints the same structure the MCP tools return. Every finding has a layer, a technique id, a plain-English detail and a count. Real output for BLA's v6 vault.cjs, shortened:

{
  "tool": "LASIK", "version": "0.1.0", "mode": "scan",
  "target": "./bench/bla-crackme/v6/vault.cjs",
  "files": [{
    "file": "vault.cjs", "format": "javascript",
    "bytesBefore": 164580, "bytesAfter": 5640,
    "tokensBefore": 42600, "tokensAfter": 1481,
    "findings": [
      { "layer": "entangle", "technique": "corpus-digest-interlock",
        "detail": "recomputed the decoy-corpus digest statically and folded the anti-strip seed bit", "count": 1 },
      { "layer": "prompt", "technique": "interlock-safety-corpus",
        "detail": "LLM-directed decoy corpus (vectorId / classifierDomain / triggerPayload)", "count": 1 },
      …
    ],
    "warnings": [], "healed": true
  }],
  "totals": { "files": 1, "blinded": 1, "findings": 1109,
              "bytesBefore": 164580, "bytesAfter": 5640, "tokensBefore": 42600, "tokensAfter": 1481 },
  "blindness": 85,
  "verdict": "blinded",
  "evasion": ["deceive/fingerprinted-decoy", "deceive/honey-sourcemap", "deceive/keep-alive-anchor", …]
}

evasion lists each distinct AI-evasion technique found, as layer/technique. Its length is the "AI-evasion techniques found" number.

CI gate

--fail-on <suspected|blinded> exits with code 3 when the verdict reaches that level. Use it to stop a build that vendors code built to hide from AI review.

- uses: actions/setup-node@v4
  with: { node-version: 22 }
- run: npx -y lasik-agents scan vendor/ --fail-on blinded

Library

import { run, healJs, firewallText } from "lasik-agents";

const report = run("./dist", "heal", { outDir: "./dist.lasik" });
console.log(report.verdict, report.blindness, report.totals);

const { code, findings } = healJs(source, { filename: "bundle.js" });
const { text } = firewallText(untrustedString);

Responsible use

LASIK is a deobfuscator. Use it on software you own, malware and threat samples, CTFs and challenges (like BLA's CrackMes), and code you are authorised to audit. Removing protection from someone else's software can breach its licence or laws such as the US DMCA §1201. See DISCLAIMER.md.
